# ChatGPT connector

**Status: Planned**. This project has no working ChatGPT Web connector, MCP URL
or OAuth flow. No account tier or client version has been validated.

M1.1 and M3.3 must verify the current official client requirements, supported
MCP transport, OAuth discovery/registration, consent, tool availability and
error handling. Validate host/workspace/thread selection and user isolation with
a real integration before publishing connection instructions.

Do not add the scaffold to a client as if it were a working service. The example
origin `https://gateway.example.com` is illustrative only. No tool is
registered. See [MCP tools](mcp-tools.md) and
[authentication](authentication.md).
