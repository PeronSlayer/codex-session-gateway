# Support

**Status: Implemented** — support policy; hosted issue availability is unverified.

For scaffold development, consult [development](docs/development.md) and
[troubleshooting](docs/troubleshooting.md). Once the intended public repository is
created, use its issue templates for sanitized bugs or proposals tied to ROADMAP
items. Do not assume planned connectors or deployment methods already work.

Include the project revision, Node/pnpm versions, command and a minimal sanitized
failure description. Do not attach full environment dumps, sessions, credentials,
private source files or raw transcripts. No support response time is guaranteed.

For vulnerabilities use [SECURITY](SECURITY.md); for conduct concerns use the
[Code of Conduct](CODE_OF_CONDUCT.md). Neither should be reported with sensitive
details in public issues.
